# Full-site audit — 2026-08-29

Seven SME auditors (`AUTONOMY.md` roster) run in parallel, **report-only**. No app code,
content, or tooling was changed by this pass. Findings are deduped and ranked below, each
tagged with the implementer it routes to.

Environment note: the container had no vendored browser. `chrome-headless-shell` had to be
copied (not symlinked) into `./chrome-headless-shell/local/` — see FIND-07.

## Cross-cutting themes

Three patterns recur across independent auditors and matter more than any single finding.

**1. Confident top-line outputs contradict correct information sitting nearby.**
FIND-01 (wizard verdict vs. the CA salary floor shown two paragraphs below it), FIND-02
(`OR.json` headline `value` vs. its own hedging `notes` field), FIND-05 (suggested chat prompt
vs. what the router returns). In each case the app holds the right data and leads with the
wrong summary. For a legal-information tool aimed at distressed non-lawyers who stop reading
at the bolded verdict, this is the highest-severity class of defect in the product.

**2. Safeguards that pass or warn without doing their job.**
FIND-03 (`check-artifacts-fresh` cannot fail in the chain that runs it), FIND-04
(`check-fallback-freshness` warns and exits 0, so staleness drifts indefinitely), FIND-08
(`agencies{}.url` is never validated), FIND-06 (the skip path drops the deadline card with no
notice). Each is individually small; together they mean several green signals are not
evidence of the thing they appear to attest.

**3. A fix computed against an assumption that no longer holds.**
FIND-09: a prior contrast fix derived its target colors from a single-layer composite, but the
element renders inside a second translucent panel. The comment documenting the fix is still
there and still wrong. Worth a lint that walks nested translucent cards rather than a one-off
recolor.

## P0

**FIND-01 — Exemption wizard can tell a California worker she is exempt when state law says
otherwise.** → `wl-builder`
Inputs: $52,000/yr ($1,000/wk), manages 2+, has hire/fire authority. Headline renders
"Possibly exempt — executive. You appear to meet the executive exemption." CA's white-collar
salary floor is ~$1,352/wk; she is $352/wk below it and therefore **not** exempt in CA. The
app displays the $1,352 figure on the same screen as an abstract paragraph and never applies
it to the salary already stored in `profile.salary`. This is the exact persona the tool exists
for, and the output can reinforce an employer's incorrect classification.
Fix: in `computeWizardResult`, when state data carries a numeric salary-floor fact, compare it
against the user's stored weekly rate and downgrade or annotate the top-line verdict.

**FIND-02 — `content/states/OR.json` overstates the BOLI filing deadline.** → `wl-content`
`deadlines.discriminationComplaint` reads `"5 years"`. That conflates two deadlines: the
**administrative** complaint window with BOLI is **1 year** (ORS 659A.820). Five years applies
only to a **civil action**, and only for the claim types enumerated in ORS 659A.875. A user
relying on the stated figure to time a BOLI filing would miss the real deadline.
Sources: https://www.oregon.gov/boli/workers/pages/discrimination-at-work.aspx ,
https://oregon.public.law/statutes/ors_659a.875

**FIND-03 — `check-artifacts-fresh` is vacuous inside `npm run verify`.** → `wl-backend`
`verify` runs `node build.mjs` *before* `automation/check-artifacts-fresh.mjs`. The check
exists to prove committed `index.html`/`assets/app.js` match a fresh build of committed
`index.dev.html`, but the build one step earlier already overwrote both — it compares a
just-built file to another just-built file. Demonstrated: editing `index.dev.html` without
rebuilding fails the check standalone, passes it in `verify` order, and the drift is silently
baked into the artifacts.
Fix: run the check *before* `build.mjs`, or diff against `git show HEAD:index.html`.

## P1

**FIND-04 — `CONTENT_FALLBACK_BASE` pinned 34 commits behind `origin/main`.** → `wl-builder`
Threshold is 20. Users on the degraded-network CDN-fallback path are served stale legal
content. `check-fallback-freshness` detects this but exits 0 by design, so it warns into the
void. For an app whose value is current law, a silent stale-content path deserves a gate.

**FIND-05 — The app's own suggested chat prompt returns the wrong body of law.** →
`wl-builder` (routing) + `wl-content` (missing topic)
The seeded quick-reply "Is this a wrongful termination?" matches the retaliation router's
`/\bterminat\w*/`, so it answers with Fla. Stat. §448.102 (whistleblower) — a different legal
theory from a discrimination-based firing. `REPLIES[]` has no wrongful-termination topic at
all, so the button the app suggests has no correct answer behind it. Reproducible on every
load.

**FIND-06 — "Skip to dashboard" silently drops the deadline countdown.** → `wl-builder`
With `stateSel`/`issue` unset, Home renders no Deadline Watch card and no prompt to get one.
The shortcut the app itself offers removes its most time-critical widget, with no indication
anything is missing — worst for the hurried user the shortcut is aimed at.
Fix: render an "Add your state to see your filing deadline" CTA in that slot.

**FIND-07 — Chrome discovery is copy-pasted across all 52 test files.** → `wl-qa`
Each shells out to `find "${ROOT}chrome-headless-shell" -type f -name 'chrome-headless-shell'`.
`-type f` does not match symlinks, and nothing checks the result is non-empty before
`puppeteer.launch()`, so a missing browser surfaces as a generic puppeteer error rather than
the documented gotcha. CI is unaffected (it installs a real file via `--path .`); this bites
local and container setups.
Fix: centralize in `test/lib/`, add `-L` or use `@puppeteer/browsers`' `computeExecutablePath`,
and fail fast with an actionable message.

**FIND-08 — `agencies{}.url` bypasses content validation.** → `wl-backend`
`automation/validate-content.mjs` checks only `facts[].sourceUrl` for official-domain hygiene.
Three agency links sit on non-`.gov` hosts (`fchr.myflorida.com`, `khrc.net`, `laworks.net`) —
all spot-checked genuine, so not wrong facts, but a silent gap where a bad link ships
unflagged.

**FIND-09 — Nested translucency drops deadline text below AA contrast.** → `wl-builder`
Action-first mode: `FlsaSolNote` / `DeadlineComputedBlock` render inside the Deadline Watch
`surfacefx` button (`rgba(255,255,255,.14)`) and set the same alpha again, stacking two
overlays on `#2B3AA8`. True composited background is `rgb(98,109,191)`, not the
`~rgb(73,86,180)` the existing fix comment at `index.dev.html:2345` assumes.
Measured: label `#FFE3A6` → **3.76:1**; body `#FFF4D6` → **4.29:1**. Both need 4.5:1; 12px/14px
bold does not qualify as large text. Recurs in the `urgent` tone.
Fix: make the inner note opaque rather than a second alpha layer, then re-derive the tone
colors against the real composite. Add a check that walks nested translucent cards.

**FIND-10 — Action-first mode buries its own primary CTA.** → `wl-builder`
The headline renders at 40px and occupies 302px across 7 wrapped lines; "Do this step" lands
at `top:1048px` on an 844px viewport — 1.25 screens down. The mode built for speed is the
slowest to reach its action.
Fix: cap the headline at the 28–32px scale used elsewhere, or move the CTA above the Deadline
Watch explainer.

**FIND-11 — No letter fits "my accommodation was already denied."** → `wl-builder`
After logging "Requested accommodation" then "Accommodation denied", the accommodation letter
is still first-ask future tense ("I am requesting…") and the complaint letter is generic Title
VII boilerplate that never mentions ADA or disability. Neither pulls in the ADA-log entries.
The user does the work the app asked for and gets no payoff.

## Verified clean (negative results worth keeping)

- **Security:** no exploitable XSS or exfiltration path. `safeUrl()` allowlists `https://`;
  letter export HTML-escapes before `document.write`; all `target="_blank"` carry
  `rel="noopener noreferrer"`; CSP hash-pinned per build with `object-src`/`base-uri 'none'`;
  CDN scripts SRI-pinned. A seeded-case network trace showed only same-origin `content/*.json`.
  Independently corroborated by QA: a 25,000-char note containing an inline `<script>` payload
  did not execute.
- **Framebusting:** in a sandboxed iframe the guard throws `SecurityError`, aborting before
  React mounts — blank page, not a clickjackable app. Not exploitable; no fix needed.
- **Attachments:** SVG/HTML excluded from the allow-list with MIME re-validated server-side of
  the `accept` attribute. Sound.
- **Content integrity:** `index.json` matches disk in both directions (50 states, no DC/PR);
  all 9 required fields present on every fact; `reviewed:false` everywhere; no duplicate topics.
- **Jurisdiction correctness:** TX cites `Tex. Labor Code § 21.002(8)`, NY cites
  `N.Y. Exec. Law § 292(5)`; TX wage-demand correctly omits a state-overtime clause while
  CA/AK/CO/NV include one. No cross-contamination either direction.
- **Accessibility:** 0 hit-target violations; 0 unlabeled inputs; visible focus on ~230 sampled
  elements in both themes; single `<h1>` per screen; `<main tabIndex={-1}>` focused on screen
  change; disclaimer present on all 12 screens including the blocked-fetch error state.
- **Robustness:** full simulated offline degrades correctly across four screens; corrupted
  localStorage recovery and back/forward mid-wizard both hold.
- **Validators with real teeth:** `validate-content`, `check-csp`, `check-csp-sync` and
  `check-shell-fresh` were each deliberately broken and each failed correctly. FIND-03 is an
  ordering bug, not a rotten gate.
- **Icon system:** a real single-source monoline SVG set (`ICON_PATHS`), 24×24,
  `stroke=currentColor`, consistently `aria-hidden` with visible text labels.

## Two auditors corrected themselves mid-run

Recorded because the retractions are as useful as the findings: `wl-design` suspected a desktop
left-bias from a thumbnail, then measured symmetric ~323/328px margins and withdrew it.
`wl-ux` flagged a chat chip at x=597 in a 390px viewport as overflow, then found it was an
intentional `overflow-x:auto` strip with a fade mask, reachable and focusable.
